# Field review captures

- `base-new-field.webp`: beginning of the idle game, with the Entrance Hall and the first three surveyed plots. Later facilities stay hidden among the meadow until they are built.
- `base-built-field.webp`: all facilities constructed, with the staggered layout, winding path, and revised first four building sprites.

These are 960 × 576 canvas renders generated from the actual renderer with a scripted sample game state. They are visual checks, not browser interaction or playtest evidence. Several later facilities still use the old hard-edged assets, and character movement still needs authored full-body frames. Those are the next production passes.
