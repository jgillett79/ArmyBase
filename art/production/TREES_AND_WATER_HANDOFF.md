# Trees and running water: integration handoff

Four individually painted tree sprites are now displayed at existing world tree positions. The three conifers have different crowns and silhouettes; the broadleaf uses the same olive, teal and ochre palette. All exports are transparent 192 × 288 PNGs at 3 art pixels per world pixel. Their shared ground pivot is (96, 284), with the rendered box ending four art pixels below the pivot. Source paintings, export recipe and game-scale contact sheet are included in this directory and `art/review/tree-kit-v1-game-scale.png`. The existing generated tree drawing remains a loading fallback. Asset status is **provisional**, pending a desktop and phone screenshot review of foliage scale and overlap with buildings.

The stream, pond and river now draw a moving, clipped current over the cached landscape each frame. Current marks follow each water polygon's cross-section and travel downstream. The bridge deck masks current marks so they do not run through walkers' feet. There is no baked animation in the terrain sprites. Review the creek near the gate and bridge at 1× and 1.6× zoom and check that the flow direction, speed and highlights fit the still water artwork; adjust the code in `js/scenery.js` after the visual trial.

`node tests/render-data.cjs` checks current displacement and bridge clearance; `node tests/smoke.cjs` checks the game loop. Both pass. Browser pixel validation could not run in this environment because Chrome/Edge is absent. Please run `node tools/validate-assets.cjs` and capture a 30-second desktop/phone game clip before marking either feature production.
