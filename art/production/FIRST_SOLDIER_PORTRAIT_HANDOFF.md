# First soldier portrait candidate

`assets/portraits/soldier_01.png` is a transparent 256 × 256 card portrait candidate. It is derived from `art/rig/soldier_walk_down_painted_v3.png` as the **identity reference**; the full-size source is `art/production/source/soldier-portrait-01-v1.webp`. Helmet badge, face palette, olive coat, brown webbing and rifle placement follow the reference. It has no name, UI frame or baked background. The runtime file has 16 px horizontal breathing room around the figure and is intended to display at roughly 96–128 CSS px.

Use only for `soldierVariant === 1` while the matching directional walking master is reviewed. **Do not repeat this portrait for all six variants or imply different generated names have distinct portraits.** For other variants, use a neutral silhouette or a deterministic crop of the existing in-world sprite until matching portraits and directional sprites exist. If the first recruit's assigned variant is not 1, the onboarding can deliberately select variant 1 for that recruit (persist that choice) without changing anyone else's identity. Verify at game size that face, helmet and kit match on map → card → mission report → return.

Status: **candidate**. The down walk/idle passed the measured gait review, but up/right sheets and corresponding idle are not production-approved; this portrait does not remove the release gate in `CLAUDE_IMPLEMENTATION/08_FIRST_SOLDIER_CHAPTER.md`.
